# Warframe Autocaster Portable

Полная портативная сборка основного Autocaster с редактором сценариев и макросов. Использует интерфейс «Индекса» после отката Modern Dashboard.

## Быстрый запуск

1. Скачайте `WarframeAutocaster-Portable-win-x64.zip` из [Releases](https://github.com/moonspiet6-design/WarframeAutocaster-Portable/releases) и распакуйте архив целиком в папку, доступную для записи.
2. Если основной Autocaster уже открыт, выйдите из него через значок в трее. У двух сборок общий блокировщик запуска, чтобы хоткеи и ввод не конфликтовали.
3. Запустите `WarframeAutocaster.exe`. По умолчанию **F8** показывает или скрывает редактор, **F9** запускает или останавливает выбранный сценарий. Хоткеи меняются в **Settings → Hotkeys**.
4. Для переноса скопируйте всю папку. `profiles`, `settings.json` и `logs` хранятся рядом с EXE.

## Требования

- Windows 11 x64 и установленная Warframe. .NET Desktop Runtime включён в сборку. .NET 10 SDK нужен только для сборки из исходников.
- Для работы оверлея используйте оконный режим или окно без рамки. Для игрового ввода Warframe должна быть в фокусе. Запускайте игру и Autocaster с одинаковым уровнем прав.
- Для действия **Rathuum kill feed** нужен пакет распознавания текста Windows **English (United States)** и английский интерфейс игры. Считыватель ожидает английские названия палачей. Если OCR отсутствует, установите компонент Windows по инструкции Microsoft. [Проверка и установка OCR](https://learn.microsoft.com/windows/powertoys/text-extractor#supported-languages).

## Комплектные конфиги

| Конфиг | Где открыть | Запуск и проверка перед игрой |
| --- | --- | --- |
| `nidus ol` | **Macros** | **Left Alt**, включён. Сверьте клавиши способностей и маршруты. |
| `nidus aol` | **Macros** | **Mouse 5**, изначально выключен. Включите через **Macro settings → Enabled**. Для Rathuum проверьте **Compact HUD** и видимость счёта и киллфида. |
| `Nokko Index` | **Scenario** | **F9**. В **Index settings** проверьте режим решения в конце раунда и время до эвакуации. При таймере эвакуация происходит на следующем голосовании после его истечения. |

Маршруты Нидуса записаны как относительные движения. На другом ПК проверьте чувствительность в игре, DPI мыши и начальное направление камеры. При необходимости перезапишите движения.

## Сборка из исходников

С установленным .NET 10 SDK запустите в PowerShell:

```powershell
.\Build-Portable.ps1
dotnet test .\Autocaster.slnx -c Release
.\dist\WarframeAutocaster.exe --editor-test
```

В `dist` появятся EXE, README и папка `profiles`. Для чистого комплекта укажите новую папку через `-OutputDirectory`. Фоновая проверка читает встроенные конфиги, рассчитывает планы и проверяет редактор с временными данными.
