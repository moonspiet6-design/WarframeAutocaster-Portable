# Warframe Autocaster Portable

Отдельная сборка для Windows x64 с редактором макросов. В папке `profiles` лежат копии `nidus aol` и `nidus ol`.

## Сборка

Нужен .NET 10 SDK. Из этой папки в PowerShell:

```powershell
.\Build-Portable.ps1
```

Скрипт соберёт `dist\WarframeAutocaster.Portable.exe` и положит рядом папку `profiles`. Для запуска сборки .NET отдельно устанавливать не нужно. Для переноса скопируйте всю папку `dist`. Настройки и логи сохраняются там же.

## Запуск

Откройте EXE и выберите макрос. **Macro settings** содержит его настройки, включая горячую клавишу, режим шагов и HUD. **F8** показывает или скрывает редактор.

Пока открыт основной Autocaster, portable-редактор доступен, а его игровые хоткеи приостановлены. После выхода из основного приложения они включаются автоматически. У обоих макросов изначально одна клавиша **Mouse 5**, поэтому активным оставлен только `nidus aol`, как в исходных файлах.

## Проверка

```powershell
dotnet test .\Autocaster.slnx -c Release
.\dist\WarframeAutocaster.Portable.exe --editor-test
```

Фоновая проверка загружает комплектные макросы, собирает планы шагов и проверяет редактор. Она не активирует окно и не отправляет ввод.
